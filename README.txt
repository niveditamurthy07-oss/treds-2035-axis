TReDS 2035 — Enhanced Streamlit Prototype

FILES
- app.py: complete interactive demo
- requirements.txt: dependencies
- RUN_WINDOWS.bat: double-click launcher after Python is installed
- README.txt: this guide

EASIEST WAY TO RUN
1. Install Python 3.10+ from python.org.
2. Extract this folder.
3. Double-click RUN_WINDOWS.bat.
4. A browser window should open at http://localhost:8501.
5. In the app, select Base Case and click RUN WORKING CAPITAL INTELLIGENCE.

If Windows blocks the .bat file, open Command Prompt in this folder and run:
pip install -r requirements.txt
streamlit run app.py

DEMO FLOW
1. Show MSME Context.
2. Explain today's reactive TReDS.
3. Click Run.
4. Pause at the AI predictions.
5. Explain why the model predicts the funding need.
6. Show the bank marketplace.
7. Emphasize human approval.
8. End on Reactive → Predictive.

This is a deterministic presentation simulation, not a real credit/AI underwriting engine.
